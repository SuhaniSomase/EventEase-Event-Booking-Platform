# EventEase – Event Booking Platform

EventEase is a responsive event booking web application developed using HTML, CSS, and JavaScript. It allows users to explore events, filter available options, and manage their bookings through a simple interface.

## Features

- Browse and search events.
- Filter events by category.
- Sort available events.
- Book events through an interactive booking form.
- View saved bookings.
- Cancel existing bookings.
- Save booking data using browser Local Storage.
- Switch between light and dark themes.
- Responsive design for desktop and mobile devices.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser Local Storage
- Visual Studio Code
- Live Server

## How to Run

1. Download or clone the repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` using the Live Server extension.
4. Explore the events and test the booking features.

## Storage

Event bookings and theme preferences are stored in the browser's Local Storage. The data is not automatically shared across browsers or devices.

## Limitations

- This is a frontend demonstration project.
- No backend database or real payment gateway is integrated.
- Event and booking data are managed on the client side.
